# ADR 0004: אין מודל בטעינת עמוד ואין מודל בהקלדה

תאריך: 6 באוקטובר 2026
סטטוס: מוצע.

## הקשר

אביעד ביקש "הכי פחות שימוש בטוקנים" ובמקביל חיפוש שמבין כוונה, תגיות בכל עמוד, ושאלות. הדרך היחידה לקיים את שניהם היא להפריד בין מה שקורה כשגולש נמצא בעמוד לבין מה שקורה בלילה.

## החלטה

| רגע | מה מותר | מה אסור |
|---|---|---|
| טעינת עמוד | הגשת JSON שנבנה בלילה, מהמטמון | כל קריאה למודל שפה או ראייה |
| הקלדה בחיפוש | חיפוש מילולי בקוד (מיידי) | קריאה למודל |
| Enter בחיפוש | וקטור אחד לשאילתה חדשה (embedding, לא מודל שפה), נשמר במטמון | מודל שפה |
| לחיצה על תגית / "דומים" | הגשה מהמטמון | כל קריאה |
| שאלה בחלון | תשובה שמורה אם יש; אחרת scope_check → answerer → verifier | מודל לפני בדיקת תשובה שמורה |
| לילה | הכול: אינדקס, עובדות חזותיות, התאמות, ביקורת, סקירה | — |

- בדיקה אוטומטית מוכיחה שנתיבי `/w/*` חוץ מ‑`/ask` לא מפעילים אף driver.
- `/ask` מוגבל לפי אתר ולפי visitor, ועוצר כשהחלק שלו בתקציב נגמר.

## למה

- עלות שתלויה בתנועה היא עלות בלי תקרה. עלות שתלויה בשינויים בתוכן היא קטנה וצפויה.
- זמן תגובה: JSON מהמטמון מגיע בעשרות מילישניות; מודל לוקח שניות.
- עמידות: אם הספק נופל, האתר ממשיך לעבוד. רק השאלות החדשות נופלות לווצאפ.

## השלכות

- עמוד חדש מקבל תגיות רק אחרי הלילה הראשון (או אחרי "סרוק עכשיו" בפאנל). עד אז: תיבת השאלה בלבד.
- כל מה שהגולש רואה הוא תוצר שעבר ביקורת ונשמר. אין טקסט "חי" של מודל מלבד תשובות לשאלות, וגם הן עוברות verifier לפני ההצגה.
