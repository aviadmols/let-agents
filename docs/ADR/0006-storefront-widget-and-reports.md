# ADR 0006: הרכיב באתר, אירועים, הזמנות ודוחות בתוסף

תאריך: 17 בספטמבר 2026
סטטוס: התקבל. מומש ב־API ובתוסף 0.2.0.

## הקשר

אביעד ביקש לראות את הרכיב באתר, לבחור איפה הוא יופיע לפי CLASS של התבנית (ברירת מחדל: אחרי האלמנט), ולקבל בתוסף דוחות: צפיות, דפים חמים, מודלים חמים, הוספות לסל ורכישות. ADR 0005 קבע שהתוסף לא נוגע בהזמנות, והשאיר פתוח איך התוסף יזדהה מול Let Agents בכיוון ההפוך.

## החלטה

- **בלי סוד נוסף.** כל המפתחות נגזרים מ־hash הטוקן, שהתוסף כבר שומר ו־Let Agents מחזיקה את הטוקן עצמו:
  - `site key`: 24 תווים ראשונים של `sha256('let-agents-site|' + token_hash)`. ציבורי, מופיע בכל עמוד.
  - `preview key`: 32 תווים ראשונים של `hmac_sha256(token_hash, 'let-agents-preview')`. פרטי, בקישורי תצוגה מקדימה.
  - חתימה: `hmac_sha256(token_hash, timestamp \n METHOD \n path?query \n body)`, בחלון של 5 דקות.
  החלפת טוקן מחליפה את שלושתם.
- **הרכיב נטען מ־Let Agents** (`/api/v1/widget/let-agents.js`), לא מהתוסף, כדי ששיפורים יגיעו לכל החנויות בלי עדכון תוסף. הוא רץ ב־shadow DOM.
- **מיקום לפי סלקטור CSS והגדרת מיקום** (after/before/prepend/append) לכל חנות ב־Let Agents, עם כפתור צף כשאין התאמה. ברירת המחדל: `form.cart`, אחרי.
- **תוכן העמוד נבנה בקוד מעובדות מאושרות בלבד** (`/api/v1/widget/{site}/page`). אין מודל בטעינת עמוד. מחיר ומלאי מוחלפים בערכים חיים מ־Store API של החנות, וסופרלטיב מחיר שלא תואם למחיר החי לא מוצג.
- **שלושה מצבים בתוסף:** כבוי, תצוגה מקדימה (ברירת מחדל), פעיל. בתצוגה מקדימה רק מנהלים מחוברים או דפדפן עם preview key רואים את הרכיב, וגולשים אחרים נספרים כצפיות בלבד.
- **אירועים לפי `packages/event-spec`** ב־sendBeacon. השרת מאמת מול אותה סכמה, דוחה אצווה לא תקינה בשלמותה, ומתעלם ממזהה אירוע שחוזר. גולש נשמר רק כ־hash עם מלח של החנות.
- **הזמנות בלי פרטי לקוח.** זה שינוי מ־ADR 0005: התוסף שולח hash מפתחי של מספר ההזמנה, סכום, מטבע, מזהי מוצרים, כמויות וסכומי שורה, והמזהה האנונימי מה־cookie. בלי שם, מייל, טלפון, כתובת, תשלום, הערות או קופונים. השליחה רצה ברקע ב־Action Scheduler. עדיין אין נתיב כתיבה אל החנות.
- **ייחוס:** הזמנה "אחרי שימוש ב־Let Agents" אם אותו גולש פתח, לחץ או הוסיף לסל מהרכיב בחלון הייחוס (ברירת מחדל 7 ימים). "הכנסה דרך Let Agents" היא רק שורות של מוצרים שנוספו לסל מהרכיב.
- **דוח אחד לשלושה מסכים:** `BuildShopReport` משרת את דף הדוחות בתוסף (בקשה חתומה), את פאנל המפעיל ובהמשך את פאנל הסוחר.

## השלכות

- מדיניות הפרטיות של החנות צריכה להזכיר cookie אנליטי אנונימי (`let_agents_vid`).
- אירועים נמחקים אחרי `analytics.retention_days` (ברירת מחדל 400). הזמנות נשמרות.
- בניסוי holdout עתידי השדה `holdout` כבר קיים באירועים.
