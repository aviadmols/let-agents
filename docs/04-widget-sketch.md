# סקיצת הרכיב בעמוד — Let Agents

> **עדכון:** 2026-10-06. **סטטוס:** סקיצה לאישור. גרסה חיה ולחיצה, בסעיף 9 של הדף המרונדר: https://claude.ai/artifact/U9Nyj1Cfii6HDPAHnWwPsB
> **מה זה המסמך:** איך נראה הרכיב שנטען לפי class בעמוד מוצר, בעמוד מאמר ובחיפוש: המצבים, הטקסטים, ומה נלקח מעיצוב האתר. הדוגמה: עמוד של "עץ אורן מוקצע 42×92" בחנות חומרי בניין.

---

## 1. מה הרכיב, במשפט

שורה אחת שקטה מתחת לסיכום המוצר, עם שלוש עד שש תגיות של "תרצו לראות גם". לחיצה על תגית פותחת פאנל עם הפריטים. בכל פריט: הוספה לסל ו"דומים". תגית אחת היא תמיד "יש לכם שאלה?" ופותחת את השאלות הנפוצות ותיבת טקסט.

---

## 2. המצבים

### 2.1 סגור: שורת התגיות (בתוך העמוד, אחרי ה‑class שהוגדר)

```
┌──────────────────────────────────────────────────────────────────┐
│  [סיכום המוצר של האתר: שם, מחיר, כפתור הוסף לסל]                  │
├──────────────────────────────────────────────────────────────────┤
│  תרצו לראות גם                                                   │
│                                                                  │
│  ( קרשים דומים 12 )  ( ברגים לדק 8 )  ( מקדחות ומברגות 6 )       │
│  ( חומרי הגנה לעץ 5 )  ( מדריכים 3 )  ( ? יש לכם שאלה )          │
└──────────────────────────────────────────────────────────────────┘
```

- הכותרת "תרצו לראות גם" היא תבנית, לא טקסט של מודל. אפשר לשנות בפאנל.
- התגיות: תווית בעברית + מספר הפריטים. הסדר נקבע בלילה לפי לחיצות.
- תגית "יש לכם שאלה" תמיד אחרונה, תמיד קיימת, גם בעמוד בלי bank.
- אין תמונות ואין טקסט נוסף במצב סגור. הרכיב לא מתחרה בעמוד.

### 2.2 פתוח: תגית של מוצרים

```
┌──────────────────────────────────────────────────────────────────┐
│  תרצו לראות גם                                                   │
│  (● קרשים דומים 12 )  ( ברגים לדק 8 )  ( מקדחות 6 )  ( ? שאלה )  │
│  ──────────────────────────────────────────────────────────────  │
│  קרשים דומים · באותו עובי, אורכים אחרים                     ✕    │
│                                                                  │
│  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐                  │
│  │ תמונה  │  │ תמונה  │  │ תמונה  │  │ תמונה  │                  │
│  │        │  │        │  │        │  │        │                  │
│  ├────────┤  ├────────┤  ├────────┤  ├────────┤                  │
│  │ אורן   │  │ אורן   │  │ אורן   │  │ אשוח   │                  │
│  │ 42×92  │  │ 42×142 │  │ 32×92  │  │ 42×92  │                  │
│  │ 3.0 מ׳ │  │ 3.0 מ׳ │  │ 4.0 מ׳ │  │ 3.0 מ׳ │                  │
│  │ 38 ₪   │  │ 54 ₪   │  │ 41 ₪   │  │ 35 ₪   │                  │
│  │[+ לסל] │  │[+ לסל] │  │[+ לסל] │  │[+ לסל] │                  │
│  │ דומים ›│  │ דומים ›│  │ דומים ›│  │ דומים ›│                  │
│  └────────┘  └────────┘  └────────┘  └────────┘                  │
│                                                   עוד 8 ›        │
└──────────────────────────────────────────────────────────────────┘
```

- שורת המשנה ("באותו עובי, אורכים אחרים") היא הסיבה שה‑picker נתן, אחרי שה‑auditor אישר אותה. אם נדחתה, אין שורה.
- "+ לסל" מוסיף דרך ה‑API של הפלטפורמה בלי לעזוב את העמוד. "דומים ›" מחליף את הרשימה בשכנים של הפריט ההוא, עם דרך חזרה.
- עד 8 פריטים. "עוד" מציג את הרזרבה. במובייל: שורה אחת גלילה אופקית.

### 2.3 פתוח: "דומים" של פריט

```
│  ‹ חזרה לקרשים דומים                                             │
│  דומה ל: אורן מוקצע 42×142                                       │
│  ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐                  │
│  │  ...   │  │  ...   │  │  ...   │  │  ...   │                  │
```

הפירורים נערמים עד עומק 3, ואז הרשימה נפתחת בעמוד המוצר עצמו. שכנים מחושבים מראש, אין קריאה למודל.

### 2.4 פתוח: תגית של מאמרים

```
│  מדריכים · לפני שבונים דק                                    ✕    │
│                                                                  │
│  ┌──────┐  איך בוחרים עץ לדק: אורן, אשוח או עץ טרופי            │
│  │ שער │  5 דקות קריאה · 3 מוצרים מהמדריך הזה נמצאים אצלכם בסל   │
│  └──────┘  פתח ›                                                 │
│  ┌──────┐  ברגים לדק: למה לא כל בורג מתאים                       │
│  │ שער │  3 דקות קריאה                                            │
│  └──────┘  פתח ›                                                 │
```

### 2.5 פתוח: "יש לכם שאלה"

```
│  יש לכם שאלה על עץ אורן מוקצע 42×92?                         ✕    │
│                                                                  │
│  ( מתאים לשימוש בחוץ? )  ( איך מחברים לדק? )  ( זמן אספקה? )    │
│                                                                  │
│  ┌──────────────────────────────────────────────────┐ [ שאל ]   │
│  │ כתבו שאלה...                                     │           │
│  └──────────────────────────────────────────────────┘           │
```

אחרי תשובה:

```
│  ▸ מתאים לשימוש בחוץ?                                            │
│                                                                  │
│    כן, עם הגנה. העץ מגיע לא מטופל, ולשימוש בחוץ מומלץ לצבוע      │
│    בלזור או בשמן לעץ לפני ההתקנה. (מתוך עמוד המוצר, מדריך "דק")  │
│                                                                  │
│    עזר?  👍  👎                      מוצרים שהוזכרו: לזור, שמן ›  │
```

כשאין תשובה בתוכן של האתר:

```
│  ▸ יש לכם עץ אורן באורך 6 מטר?                                   │
│                                                                  │
│    לא מצאנו את זה באתר. אפשר לשאול ישירות את החנות:              │
│    [ 💬 שליחה בווצאפ ]   השאלה והעמוד יצורפו להודעה.             │
```

- הצ'יפים הם שאלות שנענו בעבר (ורק כאלה ששני המודלים אישרו) ו‑FAQ שהצוות כתב. לחיצה מחזירה תשובה שמורה.
- כל תשובה מציינת מאיפה היא (עמוד המוצר, שם המדריך), ומציעה את המוצרים שהוזכרו בה.
- "עזר?" הוא האות שמאמן את סדר הצ'יפים.
- קישור הווצאפ פותח `wa.me/<מספר>?text=` עם השאלה וכתובת העמוד. השאלה נרשמת כ"ללא מענה" ונכנסת לסקירה היומית.

### 2.6 עמוד מאמר

```
│  מתוך המדריך                                                     │
│  ( המוצרים מהמדריך 7 )  ( מדריכים נוספים 4 )  ( ? יש לכם שאלה )  │
```

צ'יפ השאלה הראשון במאמר: "תסכם לי את המאמר בכמה משפטים".

### 2.7 תוצאות חיפוש (שכבה מעל טופס החיפוש של האתר)

```
┌──────────────────────────────────────────────────────────────────┐
│  🔍 קרש דק                                                  ✕    │
├──────────────────────────────────────────────────────────────────┤
│  מוצרים 14                                                       │
│  ┌────┐ אורן מוקצע 42×92 · 38 ₪      ┌────┐ אשוח 42×92 · 35 ₪    │
│  └────┘                               └────┘                     │
│  ┌────┐ עץ לדק טרופי 25×140 · 92 ₪    ┌────┐ ...                 │
│                                               כל המוצרים ›       │
│  מדריכים 2                                                       │
│  ▸ איך בוחרים עץ לדק                                             │
│  ▸ ברגים לדק: למה לא כל בורג מתאים                               │
│  דפים 1                                                          │
│  ▸ משלוחים והרכבות                                               │
│                                                                  │
│  לא מצאתם?  ( ? שאלו אותנו )                                     │
└──────────────────────────────────────────────────────────────────┘
```

- הצעות בזמן הקלדה מהחיפוש המילולי בלבד (מיידי). ה‑Enter מביא את החיפוש ההיברידי.
- שלוש הקבוצות תמיד באותו סדר. קבוצה ריקה לא מוצגת.
- "לא מצאתם?" פותח את תיבת השאלה עם השאילתה כבר בפנים. חיפוש עם אפס תוצאות נרשם.

## 3. מה נלקח מעיצוב האתר

| משתנה | נלקח מ | דריסה בפאנל |
|---|---|---|
| `--la-font` | `font-family` של body | כן |
| `--la-fg` | `color` של body | כן |
| `--la-muted` | `--la-fg` ב‑60% | כן |
| `--la-accent` | רקע הכפתור הראשי (הוסף לסל) | כן |
| `--la-accent-fg` | צבע הטקסט של אותו כפתור | כן |
| `--la-radius` | `border-radius` של אותו כפתור | כן |
| `--la-line` | `--la-fg` ב‑12% | כן |

מה שהרכיב **לא** עושה: לא מביא פונט משלו, לא צובע רקע, לא מוסיף צל. הוא נראה כמו חלק מהעמוד, או שהוא לא שם.

## 4. טקסטים

- כל המחרוזות הקבועות ("תרצו לראות גם", "דומים", "יש לכם שאלה", "לא מצאנו את זה באתר") הן תבניות בשתי השפות, לשינוי בפאנל.
- התוויות של התגיות ושורות המשנה נכתבות על ידי המודל ומאושרות על ידי המודל השני. בלי סופרלטיבים, בלי מחירים, בלי הבטחות.
- שום דבר על הרכיב לא אומר "AI", "מודל" או "חכם". הוא פשוט עוזר.

---

## 5. מובייל

- שורת התגיות גלילה אופקית, בלי שבירה.
- הפאנל נפתח כ‑sheet מלמטה, 85% גובה, עם ידית סגירה.
- רשת המוצרים הופכת לשורה גלילה. כפתור "+ לסל" נשאר בגודל מגע (44px).
- תיבת השאלה נצמדת לתחתית ה‑sheet מעל המקלדת.

---

## 6. נגישות

- כל התגיות הן `button` עם `aria-expanded`. הפאנל `region` עם `aria-labelledby`.
- ניווט מקלדת מלא: חיצים בין תגיות, Escape סוגר.
- ניגודיות: הרכיב בודק את `--la-accent` מול `--la-accent-fg`; אם נמוך מ‑4.5, נופל לטקסט כהה על רקע בהיר.
- `prefers-reduced-motion`: בלי אנימציית פתיחה.
