# Let Agents

חיפוש, גילוי ושאלות לאתרי Shopify ו‑WordPress, מתוך התוכן של האתר עצמו.

- **אינדקס** של כל מוצר, דף ומאמר, עם וקטורים לטקסט ועובדות חזותיות מהתמונות.
- **חיפוש** שסולח לשגיאות כתיב ומבין כוונה. בלי מודל שפה בזמן החיפוש.
- **תגיות בעמוד** ("תרצו לראות גם"): דומים, משלימים, לפי מאפיין, מאמרים. נטענות לפי class, נראות כמו האתר.
- **שאלות** עם תשובות מהתוכן של האתר בלבד, וווצאפ למנהל כשאין.
- **סקירה יומית** שמציעה מה להוסיף לאתר, מתוך החיפושים והשאלות של אתמול.
- **שתי משפחות של מודלים** (OpenAI ו‑Claude) שבודקות זו את זו, עם תקרת תקציב לאתר.
