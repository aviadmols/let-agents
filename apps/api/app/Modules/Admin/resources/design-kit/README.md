# ערכת עיצוב: פאנל החנות של Lets

הערכה הזו מיועדת לעיצוב מחדש של פאנל החנות, המסכים שבעל החנות רואה. העבודה נעשית על הפאנל האמיתי של החנות, עם התוכן והמידע האמיתיים שלה.

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `merchant.css` | **הקובץ שמעצבים.** כל העיצוב של פאנל החנות נמצא בו. |
| `layout/layout.js` | **הסדר והשמות:** התפריט, הטאבים והטקסטים. מסבירים עליו למטה. |
| `serve.mjs` | השרת המקומי. מריצים אותו, והפאנל נפתח אצלכם במחשב עם הקבצים שלכם. |
| `SCREENS.md` | כל המסכים בפאנל: הכתובת, קובץ ה-HTML (Blade), הכפתורים והשדות של כל מסך. |
| `CLAUDE.md` | הכללים ל-Claude שלך: מה מותר לשנות ומה אסור, כדי ששום דבר לא יישבר. |
| `views/` | קבצי ה-HTML של המסכים (Blade) כפי שהם היום, לעיון ולעריכה. |
| `examples/` | צילום של כל המסכים של סלע מאיר, לעבודה בלי אינטרנט. |
| `reference/panel.css` | שכבת העיצוב המשותפת שמתחת ל-`merchant.css`. לעיון בלבד, לא לשנות. |

## איך עובדים: הפאנל החי, מהמחשב שלכם

כך הכול עובד: כל טאב, כל סינון, כל חיפוש וכל כפתור, עם המידע האמיתי של החנות. כל מסך מוצג לפי ה-`merchant.css` וה-`layout/layout.js` שבתיקייה.

**1. מריצים את השרת.** בטרמינל, מתוך התיקייה הזו:

```sh
node serve.mjs
```

צריך Node 18 ומעלה, בלי התקנות נוספות. משאירים את הטרמינל פתוח כל זמן העבודה. אפשר גם פשוט לבקש מ-Claude: "תפרוס את ערכת העיצוב".

**2. פותחים בדפדפן את `http://localhost:5501`.** נפתח הפאנל האמיתי של החנות, בלי שם משתמש ובלי סיסמה.

- הכניסה היא קישור העיצוב שקיבלתם מאביעד, שעובד **24 שעות**. הוא שמור בקובץ `design-link.txt` שבתיקייה.
- אם הקובץ לא נמצא בתיקייה, הדף הראשון מבקש להדביק את הקישור. מדביקים פעם אחת, והוא נשמר.
- גם אם הפאנל מבקש להתחבר מחדש, השרת נכנס שוב לבד עם הקישור.
- כשהקישור פג, מבקשים מאביעד קישור חדש, ומדביקים אותו ב-`design-link.txt` במקום הקודם. אפשר גם לפתוח `http://localhost:5501/design/` ואחריו הקוד שבסוף הקישור החדש.

**3. עובדים.** עורכים את `merchant.css` או את `layout/layout.js`, שומרים, ומרעננים את הדפדפן (F5). השינוי מופיע מיד על המסכים האמיתיים.

- בפינה מופיע פס כחול **"מהמחשב שלך"**. בו מכבים ומדליקים את `merchant.css` ואת הסדר והשמות, כדי להשוות לעיצוב של היום.
- הפס השחור **"מצב עיצוב"** הוא של המערכת. כשעובדים דרך `localhost:5501` אין צורך בשדה הכתובת שבו.

> **שימו לב:** הכול אמיתי. כפתור שמאשר, מוחק או משנה הגדרה משנה את החנות האמיתית ואת מה שהגולשים שלה רואים. מותר לפתוח הכול, ללחוץ על טאבים ולסנן, אבל לא ללחוץ על פעולות בלי צורך.

**אם משהו לא עובד:**

- **הדף מבקש להדביק קישור:** אין קישור עיצוב בתיקייה. מדביקים את הקישור שקיבלתם.
- **מופיע מסך "הקישור הסתיים", או מסך התחברות:** הקישור פג או נסגר. מבקשים קישור חדש מאביעד ושמים אותו ב-`design-link.txt`.
- **"The panel did not answer":** אין חיבור לאינטרנט, או שהאתר לא זמין. מנסים שוב בעוד רגע.

## סדר ושמות: התיקייה `layout/`

כאן משנים את הסדר והשמות בפאנל, בלי לגעת בקוד. עורכים את `layout/layout.js` בכל עורך טקסט, שומרים ומרעננים.

| מה רוצים לשנות | איפה בקובץ |
|---|---|
| הסדר של התפריט בצד, השמות שלו, והסתרת פריט | `menu` |
| הטאבים שמתחת לכותרת של מסך: הסדר, השמות, ואיזה עמוד שייך לאיזה מסך | `screens` |
| התפריט הצדדי של ההגדרות והקבוצות שבו | `screens` ← `settings` |
| הטאבים שבתוך מסך, כמו "מידע כללי / פוסטים / חוקים" במרכז הידע | `tabs` |
| כל טקסט אחר: כותרת, כפתור, הסבר | `texts` |

- **להזיז:** מעבירים שורה שלמה למעלה או למטה. הסדר בקובץ הוא הסדר במסך.
- **לשנות שם:** משנים את מה שבמירכאות של `label`.
- **להסתיר:** מוסיפים `hidden: true` לשורה.
- **להעביר עמוד למסך אחר:** מעבירים את השורה שלו לרשימה של המסך האחר. אפשר גם לפתוח מסך חדש בתפריט.
- **לא משנים** את הערכים של `screen`, `page` ו-`tab`. אלה השמות שהמערכת מכירה.
- **לכל שם חדש צריך גם אנגלית.** מוסיפים `en: "..."` לאותה שורה.
- **אם יש טעות בכתיבה,** למשל פסיק או מירכאה חסרים, הפס הכחול מודיע על כך, והמסך מוצג כמו שהוא היום.
- `layout/default.js` הוא הפאנל כמו שהוא היום. לא עורכים אותו.

השינויים מוצגים אצלכם במחשב בלבד. אצל בעלי החנויות הם יופיעו אחרי שאטמיע אותם במערכת.

## בלי אינטרנט: הדשבורד המקומי של סלע מאיר

פותחים בלחיצה כפולה את `examples/index.html`. זה צילום של כל המסכים של סלע מאיר, עם התוכן האמיתי שלהם.

- התפריט והטאבים הראשיים עובדים. סינונים וכפתורים שמבצעים פעולה לא עובדים כאן, כי אין חיבור לשרת. בשבילם עובדים בפאנל החי.
- בפס התחתון מסמנים **"לעצב לפי merchant.css שבתיקייה"** ו-**"סדר ושמות לפי layout/layout.js"**.
- `examples/gallery.html` מציג את כל המסכים כתמונות, זה לצד זה.

## שינויים במבנה המסך (HTML)

- **"שמירת המסך כקובץ HTML"** בפס השחור שומרת את המסך הפתוח כקובץ, עם התוכן האמיתי שלו. אפשר לערוך אותו כהצעה למבנה חדש.
- אפשר גם לערוך ישירות את קבצי ה-Blade בתיקייה `views/`. הם לא רצים במחשב שלכם, ואני מטמיע אותם במערכת.
- סדר ושמות של תפריטים וטאבים משנים ב-`layout/layout.js`, לא ב-`views/`.
- לפני שמשנים מבנה, צריך לקרוא את `CLAUDE.md`. יש בו דברים שאסור להזיז: כפתורים שמחוברים לשרת, שדות טופס וטקסטים בשתי שפות.

## מה מחזירים

תיקייה (או zip) עם:

1. `merchant.css` המעודכן.
2. `layout/layout.js`, אם שיניתם סדר או שמות.
3. קבצי `views/` ששיניתם, באותו מבנה תיקיות.
4. קבצי HTML של מסכים, אם שמרתם והצעתם בהם מבנה חדש.
5. קובץ `CHANGES.md` קצר: מה שיניתם בכל מסך, וכל טקסט חדש שהוספתם, בעברית ובאנגלית.

אני מטמיע את השינויים במערכת, בודק שכל הפעולות עובדות, ומעלה.
