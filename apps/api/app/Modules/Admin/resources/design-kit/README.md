# ערכת עיצוב: פאנל החנות של Lets

הערכה הזו מיועדת לעיצוב מחדש של פאנל החנות, המסכים שבעל החנות רואה. העבודה נעשית על הפאנל האמיתי של סלע מאיר, עם התוכן והמידע האמיתיים שלו.

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `merchant.css` | **הקובץ שמעצבים.** כל העיצוב של פאנל החנות נמצא בו. |
| `SCREENS.md` | כל המסכים בפאנל: הכתובת, קובץ ה-HTML (Blade), הכפתורים והשדות של כל מסך. |
| `CLAUDE.md` | הכללים ל-Claude שלך: מה מותר לשנות ומה אסור, כדי ששום דבר לא יישבר. |
| `layout/layout.js` | **הסדר והשמות:** התפריט, הטאבים והטקסטים. מסבירים עליו למטה. |
| `views/` | קבצי ה-HTML של המסכים (Blade) כפי שהם היום, לעיון ולעריכה. |
| `reference/panel.css` | שכבת העיצוב המשותפת שמתחת ל-`merchant.css`. לעיון בלבד, לא לשנות. |

## הדרך הקלה: הדשבורד המקומי של סלע מאיר

פותחים בלחיצה כפולה את `examples/index.html`. אין צורך בשרת, בקישור או בהתקנה.

- זה הפאנל של סלע מאיר כפי שהוא באתר, עם התוכן האמיתי שלו: כל 39 המסכים, וכל טאב בכל מסך.
- התפריט בצד והטאבים עובדים. כפתורים שמבצעים פעולה (אישור, שמירה, מחיקה) לא עושים כלום כאן.
- בפס התחתון מסמנים **"לעצב לפי merchant.css שבתיקייה"**. מעכשיו כל המסכים מעוצבים לפי `merchant.css` שבתיקייה הזו. כל שמירה של הקובץ ורענון (F5) מציגים את השינוי.
- `examples/gallery.html` מציג את כל המסכים כתמונות, זה לצד זה.

אם צריך לראות מסך שמתעדכן בזמן אמת או פעולה שעובדת, עוברים לפאנל החי, בשלבים שלמטה.

## סדר ושמות: התיקייה `layout/`

כאן משנים את הסדר והשמות בפאנל, בלי לגעת בקוד. עורכים את `layout/layout.js` בכל עורך טקסט, שומרים, ומרעננים (F5) את הדשבורד המקומי.

| מה רוצים לשנות | איפה בקובץ |
|---|---|
| הסדר של התפריט בצד, השמות שלו, והסתרת פריט | `menu` |
| הטאבים שמתחת לכותרת של מסך: הסדר, השמות, ואיזה עמוד שייך לאיזה מסך | `screens` |
| התפריט הצדדי של ההגדרות והקבוצות שבו | `screens` ← `settings` |
| הטאבים שבתוך מסך, כמו "מידע כללי / פוסטים / חוקים" במרכז הידע | `tabs` |
| כל טקסט אחר: כותרת, כפתור, הסבר | `texts` |

- **להזיז:** מעבירים שורה שלמה למעלה או למטה. הסדר בקובץ הוא הסדר במסך.
- **לשנות שם:** משנים את מה שבמירכאות של `label`.
- **להסתיר:** מוסיפים `hidden: true` לשורה.
- **להעביר עמוד למסך אחר:** מעבירים את השורה שלו לרשימה של המסך האחר. אפשר גם לפתוח מסך חדש בתפריט.
- **לא משנים** את הערכים של `screen`, `page` ו-`tab`. אלה השמות שהמערכת מכירה.
- **לכל שם חדש צריך גם אנגלית.** מוסיפים `en: "..."` לאותה שורה.
- **אם יש טעות בכתיבה,** למשל פסיק או מירכאה חסרים, הפס התחתון בדשבורד מודיע על כך, והמסך מוצג כמו שהוא היום.
- **התיבה "סדר ושמות לפי layout/layout.js"** בפס התחתון מכבה ומדליקה את השינויים, כדי להשוות.
- `layout/default.js` הוא הפאנל כמו שהוא היום. לא עורכים אותו.

השינויים האלה מוצגים בדשבורד המקומי בלבד. בפאנל החי הם יופיעו אחרי שאטמיע אותם במערכת.

## איך עובדים על הפאנל החי

### 1. נכנסים לפאנל

מקבלים מאביעד קישור שעובד **24 שעות**. הקישור פותח את הפאנל של סלע מאיר בדפדפן. בתחתית המסך מופיע פס שחור של **"מצב עיצוב"**.

> **שימו לב:** הכול אמיתי. כפתור שמאשר, מוחק או משנה הגדרה משנה את החנות האמיתית ואת מה שהגולשים שלה רואים. מותר להסתובב ולפתוח הכול, אבל לא ללחוץ על פעולות בלי צורך.

### 2. מריצים את קובץ העיצוב מהמחשב

בטרמינל, מתוך התיקייה הזו, מריצים:

```sh
node serve.mjs
```

אם אין Node במחשב, אפשר במקום זה `python -m http.server 5500`. אפשר גם פשוט לבקש מ-Claude: "תפרוס את ערכת העיצוב". ב-`CLAUDE.md` יש לו את כל השלבים.

אחר כך, בפס "מצב עיצוב" שבפאנל, מדביקים את הכתובת `http://localhost:5500/merchant.css` ולוחצים **"לטעון"**.

אם הדפדפן שואל אם לאפשר לאתר גישה למכשירים ברשת המקומית, מאשרים: כך הוא מגיע לקובץ שבמחשב. הפס מציג אם הקובץ נטען.

מעכשיו הפאנל מעוצב לפי הקובץ שלכם. כל שמירה של `merchant.css`, ואז רענון (F5), מציגה את השינוי על המסכים האמיתיים. **"חזרה לעיצוב של האתר"** מחזיר את העיצוב הנוכחי.

### 3. שינויים במבנה המסך (HTML)

- **"שמירת המסך כקובץ HTML"** בפס התחתון שומרת את המסך הפתוח כקובץ, עם התוכן האמיתי שלו. אפשר לערוך אותו כהצעה למבנה חדש.
- אפשר גם לערוך ישירות את קבצי ה-Blade בתיקייה `views/`. הם לא רצים במחשב שלכם; אני מטמיע אותם במערכת.
- לפני שמשנים מבנה, צריך לקרוא את `CLAUDE.md`. יש בו דברים שאסור להזיז: כפתורים שמחוברים לשרת, שדות טופס וטקסטים בשתי שפות.

## מה מחזירים

תיקייה (או zip) עם:

1. `merchant.css` המעודכן.
2. `layout/layout.js`, אם שיניתם סדר או שמות.
3. קבצי `views/` ששיניתם, באותו מבנה תיקיות.
4. קבצי HTML של מסכים, אם שמרתם והצעתם בהם מבנה חדש.
5. קובץ `CHANGES.md` קצר: מה שיניתם בכל מסך, וכל טקסט חדש שהוספתם, בעברית ובאנגלית.

אני מטמיע את השינויים במערכת, בודק שכל הפעולות עובדות, ומעלה.
